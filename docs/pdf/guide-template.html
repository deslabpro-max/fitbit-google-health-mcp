ЧТО ПОЛУЧИТСЯ

Ваш ИИ-ассистент видит данные браслета

Личный сервер-коннектор связывает облако Google Health, куда синхронизируется браслет, с Claude и ChatGPT. Дальше просто пишете в любом чате — на телефоне, в браузере, на компьютере:

«Как я спал на этой неделе? Сравни с прошлой»
«Сколько шагов и калорий сегодня?»
«Какой пульс покоя за месяц, есть ли тренд?»
«Запиши обед: борщ и котлета, 700 ккал»
«Запиши стакан воды и вес 82,5»
«Были ли уведомления об аритмии?»

≈ 5 минут

Одна кнопка делает всё сама: копирует код в ваш GitHub, создаёт хранилище токенов и запускает сервер. Проверено: 17 секунд от клика до рабочего адреса.

  3. Войдите в Cloudflare или зарегистрируйтесь, разрешите доступ к GitHub
  4. Ничего не меняйте и нажмите Create and deploy 2
  5. Дождитесь зелёной сборки и скопируйте адрес сервера 3

Доступ к данным браслета

≈ 15 минут

Создаём ваше личное приложение в Google Cloud — только оно и только с вашего согласия сможет читать данные здоровья. Всё делается на console.cloud.google.com под аккаунтом, к которому привязан браслет.

2.1 · Проект и Google Health API

  1. Выбор проекта (слева сверху) → New project → любое имя → Create
  2. В поиске: Google Health API → Enable 1

2.2 · Экран согласия и Test users

  1. OAuth consent screen: имя, ваш e-mail, External, режим Testing
  2. Audience → Test users → Add users → свой адрес Google 2

ЧАСТЫЕ ВОПРОСЫ
access_denied в окне GoogleАккаунт не добавлен в Test users (шаг 2.2). Добавьте и подключитесь заново.
redirect_uri_mismatchАдрес в клиенте Google не совпадает с адресом сервера + /callback. Сверьте до буквы, без слэша на конце.
«Google hasn’t verified this app»Норма: приложение ваше личное. Нажимайте Continue.
Ошибка 403 SERVICE_DISABLEDНе включён Google Health API (шаг 2.1).
Просит переподключиться раз в неделюВ режиме Testing Google ограничивает токен ~7 днями. Лечится: OAuth consent screen → Publish app.
Пульс есть, а шаги пустыеСводки нового устройства Google считает с задержкой до нескольких часов — коннектор покажет диагностику.
Нет данных вообщеБраслет не синхронизирован: откройте приложение Fitbit. «Статус браслета» покажет время синхронизации.
В ChatGPT нет кнопки CreateНе включён Developer mode или план Free.
