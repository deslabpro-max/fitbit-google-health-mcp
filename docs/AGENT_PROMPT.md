# Промт: установка коннектора с помощью ИИ-агента

Не хотите делать шаги руками? Откройте на компьютере ИИ-агента, который умеет
работать в терминале — **Claude Code** или **OpenAI Codex** (CLI, приложение
или расширение для редактора), — и вставьте промт ниже целиком.

Агент сам выполнит всё, что делается в терминале (скачает код, установит
зависимости, развернёт сервер, пропишет ключи), а шаги, которые возможны
только в браузере (вход в аккаунты, Google Cloud Console, окна согласия),
проведёт с вами по одному клику. Секреты вы вводите сами — прямо в
терминал, не в чат.

Что нужно заранее: компьютер с Windows, macOS или Linux, бесплатные аккаунты
GitHub и Cloudflare, Google-аккаунт с привязанным браслетом Fitbit.

---

```text
Ты — мой помощник по установке. Установи мне личный коннектор
«Fitbit / Google Health → Claude и ChatGPT» строго по инструкции из
репозитория https://github.com/deslabpro-max/fitbit-google-health-mcp.
Перед началом прочитай целиком README.md и docs/SETUP.md — это источник
истины; если что-то в этом промте с ними расходится, прав репозиторий.

ПРАВИЛА
- Всё, что делается в терминале, делай сам: git, Node.js/npm, npx wrangler.
  Перед каждой командой одной фразой объясняй, что она делает.
- Шаги, которые возможны только в браузере (вход в аккаунты, Cloudflare
  Dashboard, Google Cloud Console, окна согласия), не выдумывай и не делай
  вслепую: давай мне точные клики по одному шагу и жди, пока я напишу
  «готово». Если у тебя есть управление браузером — можешь нажимать сам,
  но на экранах входа и согласия останавливайся и передавай управление мне.
- Секреты (Client secret, токены, пароли) я в чат НЕ присылаю. Когда нужно
  их задать, запусти `npx wrangler secret put <ИМЯ>` и попроси меня ввести
  значение прямо в терминал.
- Ничего не удаляй и не меняй в моих существующих воркерах Cloudflare и
  проектах Google Cloud, кроме того, что создаёшь для этой установки.
- При ошибке сначала сверься с разделом «Частые проблемы» в docs/SETUP.md.
- После каждого шага коротко пиши: что сделано, что дальше.

ПЛАН
1. Проверь, что установлены git и Node.js LTS (node -v, git --version).
   Если нет — подскажи, как поставить под мою ОС, и дождись меня.
2. Склонируй репозиторий в удобную папку и выполни npm install.
3. npx wrangler login — откроется браузер, я подтвержу вход в Cloudflare.
4. npx wrangler kv namespace create OAUTH_KV — впиши выданный id в
   wrangler.jsonc (биндинг OAUTH_KV), если wrangler не сделал это сам.
5. npx wrangler deploy. Запомни адрес воркера
   (https://<имя>.<поддомен>.workers.dev), открой его и убедись, что
   показывается страница «Коннектор Fitbit Air → Claude».
6. Google Cloud (docs/SETUP.md, часть 2):
   - если установлен и авторизован gcloud — создай проект и включи
     Google Health API командами (gcloud projects create …,
     gcloud services enable health.googleapis.com); не вышло — через
     консоль по кликам;
   - экран согласия (External, режим Testing), мой адрес в Test users и
     OAuth-клиент типа «Web application» с Authorized redirect URI
     https://<адрес воркера>/callback — только через консоль: веди меня
     по шагам. Напомни, что Client secret показывают один раз.
7. npx wrangler secret put GOOGLE_CLIENT_ID, затем
   npx wrangler secret put GOOGLE_CLIENT_SECRET — значения ввожу я.
8. Объясни подключение:
   - Claude: Settings → Connectors → Add custom connector →
     https://<адрес воркера>/mcp → Connect → окно Google → разрешить;
   - ChatGPT (Plus/Pro): Settings → Apps & Connectors → Advanced →
     Developer mode → Create → тот же URL, авторизация OAuth.
9. В конце дай сводку: адрес сервера, что создано (воркер, KV, проект
   Google, OAuth-клиент), и фразы для проверки в чате:
   «Покажи статус браслета», «Сводка за сегодня», «Запиши стакан воды».
```
