# Подключаем браслет Fitbit к Claude и ChatGPT — подробная инструкция

Эта инструкция — для обычного пользователя без опыта программирования.
По шагам поднимем **личный бесплатный сервер-коннектор**, через который
ИИ-ассистент сможет читать данные вашего браслета и вести дневник питания,
воды и веса. Время на всё — 30–40 минут, из инструментов нужен только браузер.

Что получится в итоге — в любом чате с ИИ можно писать:

- «Как я спал на этой неделе? Сравни с прошлой»
- «Сколько шагов и калорий сегодня?»
- «Какой пульс покоя за месяц, есть ли тренд?»
- «Запиши обед: борщ и котлета, примерно 700 ккал»
- «Запиши стакан воды» / «запиши вес 82,5»
- «Были ли уведомления об аритмии?»

## Как это работает и почему это безопасно

Браслет синхронизируется с приложением Fitbit, данные попадают в облако
Google (Google Health API). Мы разворачиваем на бесплатном тарифе Cloudflare
**ваш личный сервер** (по протоколу MCP — его понимают Claude и
ChatGPT), который умеет читать эти данные после того, как вы разрешите доступ
через обычное окно входа Google.

Важные моменты:

- сервер — ваш личный, чужих серверов и «сервисов-посредников» в цепочке нет;
- доступ к данным — только на чтение (плюс запись ручных логов: еда, вода,
  вес); испортить данные браслета невозможно в принципе;
- все ключи и токены хранятся только в вашем Cloudflare-аккаунте;
- всё используемое — бесплатные тарифы, карта нигде не нужна.

## Что понадобится

1. Браслет/часы Fitbit (Air, Charge, Inspire, Sense, Versa…) или Pixel Watch,
   привязанные к Google-аккаунту (приложение Fitbit на телефоне).
2. Бесплатный аккаунт [GitHub](https://github.com/signup) — туда скопируется
   код коннектора.
3. Бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up) — там
   будет работать сервер.
4. Google-аккаунт (тот же, к которому привязан браслет).
5. Подписка на ИИ: Claude (кастомные коннекторы доступны на платных планах)
   или ChatGPT Plus/Pro (нужен Developer mode).

## Часть 1. Разворачиваем сервер на Cloudflare (5 минут)

1. Откройте репозиторий проекта:
   **github.com/deslabpro-max/fitbit-google-health-mcp**
2. Нажмите в README кнопку **Deploy to Cloudflare**.
3. Войдите в Cloudflare (или зарегистрируйтесь) и разрешите доступ к GitHub.
4. На странице настройки Cloudflare предложит: имя новой копии репозитория
   (останется у вас на GitHub), имя воркера (можно оставить
   `fitbit-health-connector`) и хранилище. Ничего менять не обязательно —
   жмите **Create and deploy**.
5. Cloudflare сам склонирует код, создаст хранилище для токенов (KV),
   соберёт и запустит сервер. Через минуту-две вы увидите адрес вида:

   ```
   https://fitbit-health-connector.ВАШ-ПОДДОМЕН.workers.dev
   ```

   (если на экране настройки вы задали другое имя воркера — в адресе и во всех
   примерах ниже будет оно). **Скопируйте адрес** — он понадобится дальше.
   Откройте его в браузере: если видите страницу «Коннектор Fitbit Air →
   Claude» — сервер работает.

> Запасной путь без кнопки (если что-то пошло не так): создать воркер вручную
> и настроить сборку из Git — см. раздел «Ручная установка» в README
> репозитория.

## Часть 2. Google Cloud: даём серверу доступ к данным браслета (15 минут)

Здесь мы создаём **ваше личное** приложение в Google Cloud — только оно (и
только с вашего согласия) сможет читать данные здоровья.

### 2.1. Проект и включение Google Health API

1. Откройте [console.cloud.google.com](https://console.cloud.google.com),
   войдите в Google-аккаунт, к которому привязан браслет.
2. Сверху слева нажмите выбор проекта → **New project / Создать проект** →
   любое имя (например, `fitbit-connector`) → Create.
3. В поиске сверху наберите **Google Health API** → откройте страницу API →
   **Enable / Включить**.

### 2.2. Экран согласия и Test users

1. В поиске наберите **OAuth consent screen** (или откройте
   «Google Auth Platform»). Если попросят — заполните минимум: имя
   приложения (любое), ваш e-mail, тип аудитории **External**, режим —
   **Testing / Тестирование**.
2. В разделе **Audience** найдите **Test users** → **Add users** → добавьте
   **свой** Google-адрес (тот самый, с браслетом). Без этого при подключении
   будет ошибка `access_denied`.

### 2.3. OAuth-клиент для сервера

1. Раздел **Clients / Клиенты** (он же Credentials → OAuth client ID) →
   **Create client / Создать клиент**.
2. Тип приложения: **Web application / Веб-приложение** (не «Desktop»!).
3. Имя — любое, например `health-connector`.
4. В **Authorized redirect URIs / Разрешённые URI перенаправления** →
   **Add URI** → вставьте адрес из Части 1 плюс `/callback`, например:

   ```
   https://fitbit-health-connector.ВАШ-ПОДДОМЕН.workers.dev/callback
   ```

   Без пробелов и без слэша на конце.
5. **Create**. Появится окно с **Client ID** (длинный, оканчивается на
   `.apps.googleusercontent.com`) и **Client secret** (начинается с `GOCSPX-`).
   ⚠️ **Секрет показывают один раз** — сразу скопируйте оба значения в
   заметки (или нажмите Download JSON).

## Часть 3. Передаём ключи серверу (3 минуты)

1. Панель Cloudflare → **Compute → Workers & Pages** → ваш воркер
   `fitbit-health-connector` → вкладка **Settings** →
   **Variables and Secrets** → **Add**.
2. Первый секрет: Type **Secret**, имя `GOOGLE_CLIENT_ID`, значение — Client
   ID из шага 2.3 → Save.
3. Второй: Type **Secret**, имя `GOOGLE_CLIENT_SECRET`, значение — секрет
   `GOCSPX-…` → Save.

Имена — ровно такими заглавными буквами. На этом настройка сервера закончена.

## Часть 4а. Подключаем к Claude

1. [claude.ai](https://claude.ai) → **Settings → Connectors**
   (Настройки → Коннекторы).
2. **Add custom connector / Добавить пользовательский коннектор** → в поле URL:

   ```
   https://fitbit-health-connector.ВАШ-ПОДДОМЕН.workers.dev/mcp
   ```

3. **Add**, затем у появившегося коннектора — **Connect**. Откроется окно
   Google: выберите аккаунт с браслетом. Google предупредит, что приложение
   не проверено («Google hasn't verified this app») — это **ваше собственное**
   приложение в режиме тестирования; жмите **Continue**, затем разрешите
   доступ (пункты про активность, сон, метрики — только чтение, плюс запись
   ручных логов).
4. Готово: коннектор работает во всех чатах Claude — в браузере, на телефоне
   и в десктоп-приложении. Проверка: спросите «сколько шагов я сегодня
   прошёл?».

## Часть 4б. Подключаем к ChatGPT

Кастомные MCP-коннекторы в ChatGPT доступны на планах **Plus / Pro** (в
Business/Enterprise — если разрешил администратор) и включаются через режим
разработчика.

1. ChatGPT (веб или десктоп) → аватарка → **Settings**.
2. Раздел **Apps & Connectors** (Приложения и коннекторы) → внизу
   **Advanced settings** → включите **Developer mode**.
3. Вернитесь в **Apps & Connectors** → **Create / Add connector** (кнопка
   появляется после включения Developer mode).
4. Заполните: имя `Fitbit`, MCP Server URL:

   ```
   https://fitbit-health-connector.ВАШ-ПОДДОМЕН.workers.dev/mcp
   ```

   Authentication: **OAuth**. Отметьте галочку доверия и создайте коннектор.
5. ChatGPT откроет то же окно Google — Continue → разрешить.
6. В чате коннектор подключается через меню «+» → ваш коннектор (в
   Developer mode инструменты доступны в обычных чатах). Проверка: «покажи
   мой сон за неделю через Fitbit».

Интерфейс OpenAI часто меняется: если пункты называются чуть иначе, ищите
слова «Developer mode», «Connectors», «MCP». Официальная справка:
[help.openai.com — Developer mode and MCP apps](https://help.openai.com/en/articles/12584461).

> **А Gemini?** В приложении и на сайте Gemini свои коннекторы пока добавить
> нельзя. Для энтузиастов есть вариант через терминальный Gemini CLI — см.
> README репозитория.

## Проверка и первые вопросы

- «Покажи статус браслета» — модель, заряд, когда была синхронизация
- «Сводка за сегодня» — шаги, сон, пульс, SpO2, температура кожи
- «Запиши стакан воды 250 мл» — проверка записи
- Данные за сегодня появляются после синхронизации браслета с приложением
  Fitbit — если пусто, откройте приложение на телефоне.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `access_denied` в окне Google | Ваш аккаунт не добавлен в Test users (Часть 2.2) |
| `redirect_uri_mismatch` | URI в клиенте Google не совпадает с адресом воркера + `/callback` — проверьте до буквы, без слэша на конце |
| «Google hasn't verified this app» | Это норма: приложение ваше личное, в режиме тестирования. Continue |
| Ошибка 403 `SERVICE_DISABLED` в ответах | Не включён Google Health API (Часть 2.1) |
| Коннектор просит переподключиться | Токен отозван или истёк. В режиме «Тестирование» Google может ограничивать refresh-токен ~7 днями — либо переподключайтесь, либо в OAuth-настройках нажмите «Publish app» (статус In production; предупреждение о непроверенном приложении останется — это ок) |
| Шаги/калории пустые, а пульс есть | Данные нового устройства: Google считает суточные сводки с задержкой до нескольких часов. Коннектор сам покажет диагностику в поле `diagnostics` |
| Нет данных вообще | Браслет не синхронизирован — откройте приложение Fitbit; «Статус браслета» покажет lastSyncTime |
| В ChatGPT нет пункта Create connector | Не включён Developer mode, или план Free/Business без разрешения админа |

## Обновления коннектора

Кнопка Deploy создала **вашу копию** репозитория на GitHub с автосборкой:
любое изменение в ней автоматически передеплоивается. Новые версии из
оригинального репозитория можно подтянуть через GitHub: **Sync fork /
Compare** → merge → Cloudflare пересоберёт сам.
